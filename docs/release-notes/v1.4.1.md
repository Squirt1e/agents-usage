macOS 菜单栏用量面板，**通用二进制（Intel + Apple Silicon）**，未做 Apple 公证。

## 安装

1. 打开 dmg，把 `Agents Usage.app` 拖进“应用程序”。
2. ad-hoc 签名，首次启动会被 Gatekeeper 拦下，任选一种放行：`xattr -dr com.apple.quarantine "/Applications/Agents Usage.app"`，或双击后到 **系统设置 → 隐私与安全性** 底部点 **仍要打开**。
3. 应用只在菜单栏，不占 Dock：点击图标（左右键都行）打开菜单，菜单里可显示或隐藏面板、切换「标准模式 / 极简模式」与主题、打开设置或退出。

## 这个版本里有什么

面板默认常驻并换上更清晰的深色配色；极简竖栏新增可收起的拖动把手和刷新反馈，修正零额度圆环显示。

## 说明

- **校验**：`shasum -a 256 <文件>` 与资产页上的 SHA-256 比对。
- **环境**：macOS 10.15 及以上；GLM / DeepSeek 填各自的 API Key，Codex 需本机登录 CLI，凭据存 Keychain。
- **限制**：GLM 钱包与 DeepSeek 网页用量走非公开接口，可能失效；设置窗口内的键盘操作可能收不到按键；只支持 macOS。
- **源码**：构建方式见 [README](https://github.com/Squirt1e/agents-usage#readme)。本项目以 [MIT](https://github.com/Squirt1e/agents-usage/blob/main/LICENSE) 许可开源。
